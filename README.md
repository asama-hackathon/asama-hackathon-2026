# Asama Hackathon 2026
### Inter-UWC Online Programming Competition

**Theme:** Bridging Borders
**Organized by:** UWC ISAK Japan Programming Club
**Edition:** 1 — 2026

---

## Competition Structure

### Track A — Algorithmic Challenge
Online algorithmic challenge on HackerRank.
Individual or pairs. Three difficulty levels: Beginner, Intermediate, Advanced.

### Track B — Open Project
Build a project responding to the theme.
Teams of 2 to 4 students. Submit via GitHub using our template.
